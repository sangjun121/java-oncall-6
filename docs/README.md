# 개발자 비상근무 - [BE] 조상준
# 1. 어플리케이션 설명
- 비상 근무일은 평일과 휴일로 구분된다.
- 비상 근무자는 평일 1회 휴일 1회 편성된다.
- 2일 연속 근무는 불가능하다.
  - 1. 평일, 휴일이 연속으로 나오는 경우, 다음 휴일 근무자가 먼저 배정받는다.
  - 2. 휴일, 평일이 연속으로 나오는 경우, 다음 평일 근무자가 먼저 배정받는다.

## 1-1. 규칙
- 근무자 이름은 최대 5자이다.
- 근무자는 최소 5명에서 최대 35명이다.
- 법정 공휴일 + 주말은 휴일 순번에 포함된다.

# 1. 기능 명세서

## 1. 입력 기능
- [ ] 비상근무 월과 시작 요일을 입력한다.
  - [ ] 월과 시작 요일이 올바르지 않는 경우 예외처리 (중요)
- [ ] 평일 근무자 순번을 입력한다.
- [ ] 휴일 근무자 순번을 입력한다.
  - [ ] 평일, 휴일 근무자 순번이 올바르지 않은 경우 예외처리
    - 각 순번에 근무자가 중복으로 작성된 경우 (예: 수아,수아,글로,고니,도밥,준팍)
    - 이때, 평일 근무자부터 재입력 받는다.

## 2. 입력 값 파싱
- [ ] 비상 근무 월과 시작 요일를 분리하여 저장한다.
- [ ] 평일, 휴일 근무자 순번 리스트를 각각 저장한다.

## 3. 근무자 배정
- [ ] 각 월에 포함되는 모든 날짜에 대해, 휴일인지, 평일인지 저장한다.
- [ ] 모든 날짜에 대해 순차적으로 근무자를 배정한다.
  - [ ] 바로 앞선 날짜에 동일한 근무자가 존재하는 경우, 해당 근무자 순번 리스트의 다음 근무자를 추가한다.

## 4. 출력 기능
- [ ] 각 일자에 해당하는 근무자를 출력한다.
  - 이때, 휴일인 경우, 요일 옆에 괄호로 "(휴일)"을 함께 출력한다.
